# CMPE 310 Lab 5

## C Language and Assembly

In this lab, I generated assembly code from C and C++ programs and compared the results.

### Part IA
Generated assembly from a C program without optimization using GCC.

### Part IB
Generated optimized assembly and compared it with the unoptimized version.

### Part II
Compared the assembly generated from C and C++ Hello World programs.

### Part III
Generated assembly for a while loop and wrote an assembly program to find the maximum value in an array of 10 integers.

### Result
The maximum value in the array was 23.
